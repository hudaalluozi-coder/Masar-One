# مسار ون | Masar One

بدأت مسار ون بسؤال بسيط: كيف يقدر المسعف يتابع تغيّر حالة أكثر من شخص من شاشة واحدة؟ الفكرة تجمع لوحة للمسعف وثلاث لصقات: الجبهة الممتدة إلى خلف الأذن، والصدر بشكل Y مقلوب، والرقبة بشكل فراشة.

في لوحة العرض ثلاث مساحات باسم هدى اللوزي وخالد العتيبي ومحمد الشهري. فيها حالات تدريبية تعرض تغيّر القراءات والموجات مع الوقت، وتنبيه صوتي للحالات الحرجة، ووضع فاتح وآخر داكن.

[معاينة لوحة المسعف](https://masar-one-responder.smartball8192.chatgpt.site/)

## ملفات المشروع

- [`dist/`](dist/) — واجهة لوحة المسعف.
- [`firmware/`](firmware/) — برنامج اللصقات باستخدام Arduino على لوحات ESP32-C3، وإعدادات PlatformIO.
- [`tests/`](tests/) — اختبارات الحالات التدريبية وحزم Bluetooth. أمر الاختبار من المجلد الرئيسي هو `npm test`.
- [`docs/licenses/`](docs/licenses/) — تراخيص الخط وأدوات قراءة الباركود وتوليد صورته.

## رفع البرنامج على اللصقات

إعدادات الرفع موجودة في `firmware/`، وهو المجلد الذي يُفتح في VS Code مع إضافة PlatformIO IDE. يتم رفع البرنامج لكل لوحة ESP32-C3 على حدة. لكل لصقة بيئة خاصة بها، وهذه أوامر الرفع من داخل المجلد.

| اللصقة | أمر الرفع |
| --- | --- |
| الجبهة | `pio run -e head -t upload` |
| الصدر | `pio run -e chest -t upload` |
| الرقبة | `pio run -e neck -t upload` |

## اتصال اللصقات باللوحة

لصقة الجبهة هي نقطة الاتصال باللوحة عبر Bluetooth منخفض الطاقة (BLE). تجمع قراءاتها مع قراءات لصقتي الصدر والرقبة وترسلها إلى لوحة المسعف. معرّف الطقم الافتراضي `MS1:M01`، ويظهر جهاز الجبهة باسم `MS1-M01`.

في مساحة هدى، خيار «ربط لصقة الجبهة» موجود داخل البطاقة `01` في الوضع الإلكتروني. تعرض اللوحة اتجاه القراءات الحية عند وصول الحزم. الموجات في الحالات التدريبية مخصّصة للعرض، واختبار العتاد والتحقق السريري لهما مراحل مستقلة.
