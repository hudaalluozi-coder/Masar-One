# مسار ون | Masar One

نموذج أولي للوحة المسعف ولصقات الجبهة والصدر والرقبة. يتضمن هذا الإصدار مساحات العرض لهدى اللوزي وخالد العتيبي ومحمد الشهري، والوضعين الفاتح والداكن، والحالات التدريبية وموجاتها والتنبيه الصوتي.

[فتح لوحة مسار ون](https://masar-one-responder.smartball8192.chatgpt.site/)

## الملفات

- `dist/` يحتوي على واجهة لوحة المسعف وملفاتها اللازمة للتشغيل.
- `firmware/` يحتوي على مشروع PlatformIO للبرمجة بإطار Arduino على لوحات ESP32-C3.
- `tests/` يحتوي على اختبارات السيناريوهات وحزم Bluetooth. شغّلي `npm test` من جذر المشروع.

## رفع كود اللصقات

افتحي مجلد `firmware` في VS Code مع إضافة PlatformIO IDE. وصّلي كل لوحة ESP32-C3 بمفردها واختاري بيئتها.

| اللصقة | أمر الرفع من مجلد firmware |
|---|---|
| الجبهة | `pio run -e head -t upload` |
| الصدر | `pio run -e chest -t upload` |
| الرقبة | `pio run -e neck -t upload` |

تتصل اللوحة بالجبهة عبر BLE. تجمع الجبهة قراءاتها مع قراءات الصدر والرقبة. معرّف الطقم الافتراضي `MS1:M01` واسم جهاز الجبهة `MS1-M01`. في مساحة هدى، افتحي الوضع الإلكتروني والبطاقة 01 ثم اختاري «ربط لصقة الجبهة». الموجات التدريبية للعرض، واتجاهات القراءات الحية تُعرض عند استقبال الحزم. اختبار العتاد الفعلي والتحقق السريري مرحلتان منفصلتان.
